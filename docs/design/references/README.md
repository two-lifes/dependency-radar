# Референсы стиля

Это ориентиры, а не макеты: копировать их вёрстку, тексты и иллюстрации нельзя. Как применять — `../style-guide.md`.

## 01-app-density-colors.png — админ-дашборд на shadcn/ui
**Берём:** нейтральную тёмную палитру (фон `#0a0a0a`, карточки `#171717`, рамки `#262626`); плотность (кнопки около 36px, текст 14px); карточки с тонкой рамкой без теней; светлую основную кнопку на тёмном фоне; бейджи-пилюли с обводкой; цвета точек на графиках (палитра Tailwind v4).
**Не берём:** шрифт (заменён на Geist), боковое меню (в нашем продукте одна зона — проекты), рекламные блоки.

## 02-landing-air-flat.png — лендинг студии
**Берём:** минимализм и воздух; крупный спокойный заголовок с весом 500; плоскую геометрическую графику из простых фигур без градиентов и теней; синий и розовый как акценты на чистом фоне.
**Не берём:** саму иллюстрацию (рисуем свою, тема «радар»), шрифт (у нас Geist), розовый внутри приложения.

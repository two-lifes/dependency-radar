# Dependency Radar — стайлгайд

Версия 1.0 · 18.10.2026. Значения токенов лежат в `docs/design/theme.css`, этот документ объясняет, как их применять. Как выглядит результат: `docs/design/preview.png`. Референсы с пояснениями: `docs/design/references/`.

`preview.png` демонстрирует токены, это не макет экрана. Состав таблицы, плиток и других элементов берётся из `docs/screens.md` (например, в таблице есть колонка чекбоксов, у плитки «Vulnerable» есть разбивка critical/high).

## 1. Характер

**Компактный нейтральный интерфейс приложения + воздушный плоский лендинг.**

| Взято из референса | Что именно |
|---|---|
| 01 — админ-дашборд | монохромная нейтральная палитра, тёмная тема как основная, плотность (кнопки 36px, текст 14px, строки таблицы 40px), карточки с тонкой рамкой без теней, светлая основная кнопка на тёмном фоне |
| 02 — лендинг | минимализм, flat-графика из простых геометрических фигур, много воздуха, крупный спокойный заголовок, два акцентных цвета (синий и розовый) на чистом фоне |
| Не берём из 01 | шрифт (заменён на Geist) |
| Не берём из 02 | многоцветность внутри приложения: розовый только на лендинге и в логотипе, потому что в приложении он путается с красным статусом «major/critical» |

Принципы: **плоско** (рамка 1px вместо теней; тень только у всплывающих слоёв), **один акцент** (синий), **цвет несёт смысл** (статусы), **плотность в приложении, воздух на лендинге**.

## 2. Шрифты

- **Geist Sans** — весь интерфейс. **Geist Mono** — версии пакетов, команды, идентификаторы уязвимостей, числа в таблицах.
- Подключение: пакет `geist` (`import { GeistSans } from "geist/font/sans"`, `import { GeistMono } from "geist/font/mono"`), классы-переменные на `<html>`. Лицензия SIL OFL, свободна для коммерческого использования.
- Почему не SF Pro: лицензия Apple разрешает использовать SF Pro только для макетов интерфейсов под платформы Apple, встраивать его в сайт нельзя. Geist — строгий гротеск того же класса: чёткие формы, хорош в мелких размерах, есть парный моноширинный.
- Числа в таблицах и счётчиках — `tabular-nums`, чтобы колонки не «прыгали».

### Шкала

| Токен | Размер / интерлиньяж | Начертание | Где |
|---|---|---|---|
| `text-2xs` | 11 / 16 | 500 | бейджи |
| `text-xs` | 12 / 16 | 500 | заголовки колонок таблицы, подписи плиток |
| `text-sm` | 13 / 20 | 400 | второстепенный текст, версии (mono) |
| `text-base` | 14 / 20 | 400 / 500 | основной текст приложения, кнопки |
| `text-md` | 16 / 24 | 400 | подзаголовки страниц, текст лендинга |
| `text-lg` | 20 / 28 | 600 | заголовки карточек и панелей |
| `text-xl` | 24 / 32 | 600 | заголовок страницы, числа в плитках |
| `text-2xl` | 32 / 40 | 600 | заголовки секций лендинга |
| `text-hero` | 56 / 1.1 | 500 | заголовок лендинга (на мобильных `text-2xl`: 32 / 40, 600) |

Заголовки от `text-lg` и крупнее — `tracking-tight` (−0.02em). Начертаний всего три: 400, 500, 600. Жирный 700 не используем.

## 3. Цвет

### Нейтральные поверхности

| Токен | Тёмная (основная) | Светлая | Назначение |
|---|---|---|---|
| `background` | `#0a0a0a` | `#ffffff` | фон страницы |
| `card` | `#171717` | `#ffffff` | карточки, панели, шапка таблицы-контейнера |
| `subtle` | `#1c1c1c` | `#fafafa` | заголовок таблицы, наведение на строку |
| `muted` | `#262626` | `#f5f5f5` | фон неактивных элементов, скелетоны |
| `border` | `#262626` | `#e5e5e5` | все рамки и разделители |
| `foreground` | `#fafafa` | `#0a0a0a` | основной текст |
| `muted-foreground` | `#a3a3a3` | `#737373` | второстепенный текст |

### Акцент

| Токен | Значение | Где |
|---|---|---|
| `brand` | `#324ae5` | заливки: прогресс-бар, подчёркивание активной вкладки, выбранный чекбокс, кольцо фокуса в светлой теме |
| `brand-text` | `#324ae5` светлая / `#7b8cf5` тёмная | ссылки и синий текст. В тёмной теме чистый `#324ae5` даёт контраст 3.1:1, поэтому для текста используется светлый оттенок |
| `brand-soft` | `#eef0fd` / `#151a3d` | фон полосы прогресса проверки, выбранного чипа фильтра |
| `brand-pink` | `#db406d` | только лендинг-иллюстрация и логотип |
| `primary` | `#e5e5e5` тёмная / `#171717` светлая | основная кнопка (как в референсе 01: светлая на тёмном, тёмная на светлом) |

### Статусы (одинаковые везде, ТЗ и screens.md раздел 6)

| Смысл | Токен | Тёмная: текст / фон | Светлая: текст / фон |
|---|---|---|---|
| up to date | `success` | `#00bc7d` / `#0b2a20` | `#007a55` / `#ecfdf5` |
| patch | `neutral-badge` | `#a3a3a3` / `#262626` | `#525252` / `#f5f5f5` |
| minor | `warning` | `#fe9a00` / `#2e2007` | `#bb4d00` / `#fffbeb` |
| major | `danger` | `#ff6467` / `#331314` | `#c10007` / `#fef2f2` |
| critical | `critical` | `#ffa2a2` / `#460809` | `#9f0712` / `#ffe2e2` |
| high | `danger` | как major | как major |
| moderate | `moderate` | `#ff8904` / `#2f1a08` | `#c2410c` / `#fff7ed` |
| low | `neutral-badge` | как patch | как patch |
| статус пакета active | `neutral-badge` | как patch | как patch |
| статус пакета stale | `warning` | как minor | как minor |
| статус пакета deprecated | `danger` | как major | как major |
| not checked | `neutral-badge` | как patch, рамка пунктирная | как patch, рамка пунктирная |

Все пары текст/фон проверены: контраст не ниже 4.8:1 (требование WCAG AA для мелкого текста — 4.5:1). Оценка здоровья: 80–100 `success`, 50–79 `warning`, < 50 `danger`.

### Графики
`chart-1…5`: синий, изумрудный, янтарный, фиолетовый, розовый (палитра Tailwind v4, совпадает с референсом 01). Линия здоровья — `chart-1`, столбики уязвимостей — `danger` с прозрачностью 60%.

## 4. Размеры и плотность

Сетка отступов кратна 4px. Основные значения: 4, 8, 12, 16, 24, 32, 48, 64, 96, 128.

| Элемент | Значение |
|---|---|
| Высота кнопки и поля ввода | 36px (`h-9`); маленькие — 32px; большая кнопка лендинга — 44px |
| Горизонтальный отступ кнопки | 12–16px |
| Строка таблицы | 40px; заголовок таблицы 36px |
| Отступ внутри карточки | 24px (мобильные 16px) |
| Расстояние между карточками | 16px |
| Отступы страницы приложения | 24px по бокам (мобильные 16px), сверху 32px |
| Шапка приложения | 56px, нижняя рамка 1px |
| Ширина контента | до 1280px |
| Секции лендинга | 96–128px по вертикали (мобильные 64px), ширина текста до 720px |

### Скругления
`radius-sm` 6px — бейджи, чипы, чекбоксы · `radius-md` 8px — кнопки, поля, пункты меню · `radius-lg` 10px — поповеры, плитки сводки · `radius-xl` 14px — карточки, диалоги. Бейджи-пилюли — `rounded-full`.

### Глубина
Теней нет, кроме всплывающих слоёв (дропдауны, поповеры, карточка пакета, диалоги): `shadow-overlay`. Подложка под панелью и диалогом — `black/60` в тёмной теме, `black/40` в светлой.

## 5. Компоненты

- **Кнопки:** `primary` (заливка `primary`), `secondary` (фон `card`, рамка `border`), `ghost` (без рамки, фон `accent` при наведении), `destructive` (текст и рамка `danger`, заливка только в диалоге подтверждения). Иконка + текст, иконки 16px (lucide-react), отступ между ними 8px.
- **Бейдж:** пилюля высотой 20px, `text-2xs` 500, текст и фон из таблицы статусов, рамка того же цвета с прозрачностью 30%.
- **Плитка сводки:** `card`, рамка, `radius-lg`, подпись `text-xs muted-foreground`, число `text-xl` 600 в цвете статуса. Активная плитка (применён фильтр) — рамка 1.5px `brand`.
- **Таблица:** без вертикальных линий, горизонтальные разделители `border`, заголовок `subtle` + `text-xs` 500 `muted-foreground`, наведение `subtle`, выбранная/открытая строка — полоса 2px `brand` слева.
- **Вкладки:** текст `muted-foreground`, активная — `foreground` + подчёркивание 2px `brand`.
- **Поля ввода:** фон `background`, рамка `input`, плейсхолдер `muted-foreground`, фокус — кольцо 2px `ring`.
- **Скелетоны:** `muted`, мягкая пульсация 1.5 с (отключается при `prefers-reduced-motion`).
- **Прогресс проверки:** полоса `brand-soft`, текст `brand-text`, бар высотой 4px `brand`.
- **Карточка пакета:** фон `card`, слева рамка `border`, `shadow-overlay`.

## 6. Иконки и графика

- Иконки: **lucide-react**, 16px в интерфейсе, 20px в пустых состояниях, толщина линии 1.75.
- Логотип: простой знак-«радар» (круг + сектор) в `brand`, точка в `brand-pink`. Без градиентов.
- Иллюстрация лендинга: в духе референса 02, но своя. Плоские геометрические фигуры (круги, пилюли, кольца, сектора-«радары») в трёх цветах: `brand`, `brand-pink`, белый (в светлой теме — `#0a0a0a`) на фоне `background`. Без градиентов, теней и объёма. Делается как SVG-компонент, не картинка.

## 7. Движение

Длительность 150–200 мс, кривая `ease-out`. Анимируются только прозрачность и сдвиг (появление панели справа — сдвиг на 16px + прозрачность). Подсветка обновлённой строки — фон `brand-soft`, плавно гаснет за 1.2 с. Никаких «подпрыгиваний» и параллакса. Всё отключается при `prefers-reduced-motion`.

## 8. Тёмная и светлая тема

По умолчанию тема System (как в ТЗ). Тёмная — основная для проверки дизайна и скриншотов в портфолио. Светлая обязательна по ТЗ. Переключение классом `.dark` на `<html>` (значение System — по `prefers-color-scheme`), без мигания при загрузке: тема выставляется скриптом в `<head>` до отрисовки.
